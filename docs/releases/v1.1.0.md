# 面单工坊 v1.1.0 · 自动沿用原字体

面向 Windows 10 / 11 64 位的本地 PDF 面单文字编辑器。导入 PDF、点选文字、修改内容，再另存为新文件。无需安装 Python，无需登录，面单不上传。

## 本次更新

- 默认自动沿用原字体，保留原字号、颜色、位置及粗体／斜体样式。
- PDF 内嵌字库缺字时，自动检查其他页面、本机字体和内置同款字库。
- 内置完整 Arimo 四种样式，解决同类面单新增数字、句点、KG 字符时的缺字问题。
- 找不到同款字体时明确提示，不会自动替换为其他字体家族。

## 下载与操作

1. 在下方 Assets 下载 `LabelEditor-Windows-x64-v1.1.0.zip`；`Source code` 是源码包。
2. 完整解压，打开 `LabelEditor` 文件夹，双击 `LabelEditor.exe`。
3. 点击「打开 PDF」或拖入面单。
4. 点击要修改的文字，在右侧输入新内容，保持默认自动原字体选项。
5. 点击「应用修改」，用「查看原稿」核对效果。
6. 点击「另存为 PDF」，在阅读器中按实际尺寸打印。

## 验证与支持范围

22 项自动测试通过，并完成打包程序的启动、中文编辑、Arimo 字库补全与 PDF 保存自检。字体测试使用构造的子集 PDF，不代表所有来源的实际面单都已验证。

本版支持文字型 PDF；暂不支持扫描图片改字、文字转曲还原、图片替换、批量处理或直接打印。修改单号文字不会改变条码／二维码的数据。原字体不可获得时，需要补充同款字体文件。

本版未进行代码签名。请保留完整解压目录，并核对发布来源及 SHA-256。源码以 GNU AGPL v3 提供，第三方组件遵循各自许可证。
