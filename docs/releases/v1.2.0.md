# 面单工坊 / Label Editor v1.2.0

## 简体中文

新增 macOS 原生版本，并提供中英文项目介绍、图文教程、常见问题和发布指南。应用界面目前仍为中文；英文教程提供按钮名称对照。

### 下载

| 系统 | Assets 中的文件 |
| --- | --- |
| Windows 10 / 11 64 位 | `LabelEditor-Windows-x64-v1.2.0.zip` |
| Apple M 系列 Mac，macOS 15+ | `LabelEditor-macOS-arm64-v1.2.0.zip` |
| Intel Mac，macOS 15+ | `LabelEditor-macOS-x86_64-v1.2.0.zip` |

Windows 完整解压后打开 `LabelEditor.exe`；Mac 解压后将 `LabelEditor.app` 拖入「应用程序」再打开。无需安装 Python。校验值见 `SHA256SUMS.txt`。

Mac 自动查找系统和个人字体，继续优先沿用 PDF 原字体，并内置 Arimo 四种样式补齐缺字。找不到同款字体时明确提示，不会自动改成相似字体。

Mac 版没有 Apple Developer ID 签名或公证，首次打开可能被系统拦截。核对来源后按教程使用「系统设置 → 隐私与安全性 → 仍要打开」，无需关闭系统防护。

## English

This release adds native macOS builds and bilingual introductions, illustrated guides, FAQs and publishing instructions. The app UI is currently Chinese; the English guide includes a button glossary.

Choose the Windows x64, macOS arm64 (Apple M-series), or macOS x86_64 (Intel) ZIP above. Mac builds target macOS 15 or later. Extract the whole archive; run `LabelEditor.exe` on Windows or move `LabelEditor.app` to Applications on Mac. No Python installation is required. Checksums are in `SHA256SUMS.txt`.

Mac font discovery searches system, shared and user directories. The app reuses the original PDF font and includes four complete Arimo faces. Missing fonts are reported instead of silently replaced by a similar family.

The Mac builds are ad-hoc signed, without Apple Developer ID signing or notarization. First launch may be blocked; verify the source and follow the guide's Privacy & Security instructions instead of disabling system protection.

## 支持范围 / Scope

本地编辑文字型 PDF，不上传文件。暂不支持扫描图片改字、条码重生成、图片替换、批量处理或直接打印。修改可见单号不会改变扫码数据。请对实际文件核对并试打。

Local editing of text-based PDFs; no uploads. No scanned-image text editing, barcode regeneration, image replacement, batch editing or direct printing. Visible tracking-number edits do not change encoded barcode data. Review and test-print actual documents.
