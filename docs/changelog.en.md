# Release history

[简体中文](../CHANGELOG.md) | **English**

## 1.2.0

- Add native macOS app packages for Apple Silicon and Intel.
- Discover matching fonts in macOS system, shared and user font directories.
- Use a native Chinese UI font on macOS and a platform-appropriate font picker.
- Add bilingual introductions, user guides, FAQs and build/publishing instructions.
- Build each Mac architecture separately and verify the app, signature and extracted ZIP.

## 1.1.0

- Automatically complete PDF subset fonts using the same family, weight and italic style.
- Search other PDF pages and installed Windows fonts; bundle four complete Arimo styles.
- Fix stale subset caching and select the correct face from TTC font collections.
- Display the applied font and its source.

## 1.0.0

- Initial Windows desktop editor with PDF import, text selection, editing and save-as.
- Undo/redo, original comparison, page navigation, zoom, wrapping and size controls.
- Embedded-font reuse and preservation of other content; fictitious example labels.
